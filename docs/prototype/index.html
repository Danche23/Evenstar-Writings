用 Go + Gin 从零搭建一个属于你自己的个人博客

E Evenstar 发布于 2026-08-28 👁 1,284 次浏览
文章封面图（cover 字段为空时显示前端默认封面）

最近把自己一直想做的个人博客从零搭了起来，用了 Go + Gin + MySQL + Redis。这篇文章记录几个关键的实现点，也给想入门 Go Web 开发的朋友一个参考。

1. 为什么要自己写博客

现成的博客系统很多，但自己写一遍，才能真正理解一个 Web 应用是怎么运作的——路由、鉴权、数据库、缓存、部署，每个环节都踩一遍。

2. 项目结构

backend/
├── cmd/server        # 入口
├── internal/
│   ├── api           # 路由
│   ├── handler       # 处理器
│   ├── service       # 业务逻辑
│   ├── repository    # 数据访问
│   └── model         # 实体
└── pkg/              # 通用工具

3. JWT 鉴权怎么做

登录成功后签发一个 7 天有效的 JWT，前端存起来，每次请求通过 Authorization: Bearer <token> 带上，后端中间件校验。

一个容易踩的坑：用户改密码或账号被禁用后，旧 token 应该立即失效。我在 JWT 里加了一个 token_version 字段，和数据库里的版本号比对，不一致就拒绝。

4. 小结

整个博客的核心链路已经跑通，接下来会继续完善评论、上传和后台管理。如果你也在做类似的事，欢迎在下面评论区交流。
